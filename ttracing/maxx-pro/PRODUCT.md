# TTRacing Maxx Pro manual

## Platform and purpose

A local, self-contained static HTML manual for owners assembling and using Maxx Pro. Plain HTML, CSS, JavaScript and build-time Anatomy geometry; no runtime dependencies or server. English first, confirmed by the user on 14 November 2026.

## Product scope

Gaming chair · Assembly & everyday adjustments. Manufacturer source: https://cdn.shopify.com/s/files/1/2021/9723/files/Maxx_Pro_User_Manual_-_latest.pdf?v=1784886789. Independent of other manuals: one product folder, one built index.html, no product switcher or cross-product navigation.

## Behavior

Explore selects named assemblies. Guided instructions show source-linked steps and fitting-axis separation/seating. Explicit confirmation advances and saves a product-specific review on the local device; animation never confirms physical completion. The journey and mode may be selected in the URL; reload starts at step 1. Reset guide clears the active journey only. Original PDF, fonts, logo and drawings are embedded in the single HTML for offline use.

## Illustration truth

Surface/assembly schematic with four-tone solid geometry. Motion demonstrates connections and documented controls; it is not a dimensional or force measurement. No inferred hidden electronics or service steps. See references/SOURCES.md for source limitations and discrepancies.

## Access

390px stacked layout, direct mobile step entry, explicit View illustration links, keyboard alternatives to diagram selection, native range controls, visible focus, reduced-motion stills, paused offscreen animation, and usable instructions when local storage is unavailable.

Part inspection requirement: automatically zoom and choose a task-specific angle for each part. Users can rotate horizontally and vertically to inspect the underside, zoom, select individual fittings, and return to the recommended view. Inline part references preserve the current instruction step.
