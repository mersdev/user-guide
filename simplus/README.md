# Simplus product guides

Each product has its own complete folder. Copy any folder on its own, then open its `index.html`. Each page embeds all runtime code, styles, drawings and logo.

- [LVSH001 — Water filter pitcher](lvsh001/index.html) · [folder instructions](lvsh001/README.md)
- [DKXH005 — Toaster oven](dkxh005/index.html) · [folder instructions](dkxh005/README.md)
- [DCLU001 — Induction cooker](dclu001/index.html) · [folder instructions](dclu001/README.md)
- [LLJH007 — Glass jar blender](lljh007/index.html) · [folder instructions](lljh007/README.md)
- [DKZP001 — Electric grill with hot pot](dkzp001/index.html) · [folder instructions](dkzp001/README.md)

Each folder also includes its editable source, dependency-free build/check commands, source references and screenshots. There are no shared source files or dependencies between products.

To rebuild a product, run `npm run build` inside that product folder. To check its package, run `npm run check`. No install is required.
